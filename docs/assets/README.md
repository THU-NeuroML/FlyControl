# README figure

`figure1.png` is the existing raster extract of Figure 1 on page 3 of the author-provided manuscript **A Drosophila connectome prior enables adaptable embodied control**, file `Fly_Locomotion (13).pdf`.

The four panels show closed-loop locomotion, control demands within the fly embodiment, Ant transfer/navigation and transfer across body plans. The image is copied unchanged from the manuscript extraction, at 1687 × 850 pixels. It is included solely as the repository's visual overview; generated experimental results remain outside Git.

The manuscript's first page supplies the title, author order, affiliations and corresponding-author designation displayed in the root README.
